# 🐍 Neon Snake Ultra

A modern, high-fidelity reimagining of the classic Snake game, built with Python and Pygame. This project features a cyberpunk aesthetic, particle effects, and a polished UI.

## 📸 Features

* **Cyberpunk Aesthetic:** Neon glow effects, dark grid background, and modern typography.
* **Juicy Visuals:** Particle explosions when food is eaten and pulsing food animations.
* **3 Difficulty Levels:** Easy, Normal, and Hard (Speed control).
* **Interactive UI:** Mouse-controlled Main Menu, Pause functionality, and Game Over screens.
* **Smooth Controls:** Optimized movement logic prevents accidental self-collisions.

## 🚀 Installation & How to Run

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Madhusanka1129/-Neon-Snake-Ultra
    cd Neon-Snake-Ultra
    ```

2.  **Install Dependencies:**
    You need Python installed. Then run:
    ```bash
    pip install pygame
    ```

3.  **Run the Game:**
    ```bash
    python snake_final.py
    ```

## 🎮 Controls

* **Arrow Keys:** Move Snake
* **Spacebar:** Pause / Resume
* **Mouse:** Navigate Menus

## 🛠️ Technologies Used

* **Language:** Python 3.x
* **Library:** Pygame
* **Concepts:** Object-Oriented Programming (OOP), Event Handling, Particle Systems, State Management.
